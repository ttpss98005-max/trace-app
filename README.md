# 軌跡 App

軌跡 TRACE 的 Android 原生版，直向、橫向都能用。和網站使用同一個 Firebase 專案與同一份資料。

- 每次推送都會自動編譯，APK 在 Releases 下載（trace.apk）。
- 套件名稱：tw.trace.app
- SHA-1：D1:DB:93:53:59:5B:1C:C8:89:8A:06:94:3C:7B:14:E6:3D:7B:30:66

## 第一次使用前

到 Firebase 主控台的 trace-site-26529 專案：專案設定 → 你的應用程式 → 新增 Android 應用程式，填入上面的套件名稱和 SHA-1，然後等 5 分鐘。其他步驟都可以略過，也不需要下載設定檔。
